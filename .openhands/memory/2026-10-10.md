# 2026-10-10 — go-maia web UI

## What was built
Full web UI for sceptyre/go-maia as `maia web` subcommand (local commit 6cff560 on `main`, NOT pushed):

- `cmd/web.go` — cobra cmd; resolves repo root via `git rev-parse`, chdirs, refuses non-loopback `--addr` without `--token`, listens on 127.0.0.1:7878 default.
- `internal/web/jobs.go` — JobManager: single-flight, re-exec `os.Executable()` with argv (e.g. `["init","<slug>"]`), Dir=repoRoot; per-job event log (cap 20k) with subscriber broadcast (buffered chan, drop-on-full), snapshot+subscribe atomic for SSE replay, finish/end event, cancel=flag+Kill, history prune to 20.
- `internal/web/handlers.go` — routes: state, worktrees list, doc GET/PUT (change only writable), diff (git in worktree), run (cmd whitelist: init/plan/steer/apply/commit/merge/cleanup/new + arg validation), jobs list/cancel. Slug regex `^[a-z0-9][a-z0-9-]*$` blocks traversal.
- `internal/web/server.go` — ServeMux patterns (Go 1.22 style `GET /api/{slug}`), CSP header, token middleware scoped to `/api/`, SSE handler with keepalives every 15s.
- `internal/web/render.go` — goldmark + table/strikethrough/linkify/tasklist, frontmatter stripped, raw HTML NOT rendered (safe default).
- `internal/web/static/` — index.html, styles.css (dark theme), app.js (~500L vanilla): sidebar status dots, tabs, editor w/ Cmd+S + autosave, modal helper, EventSource console with per-job buffers + resume `after`, 3s poll, `pendingSelect` auto-select after `maia new`.

## Bugs found & fixed during testing
1. `RepoName` unset → empty `repo.name` in /api/state.
2. Frontmatter rendered as `<hr>`/heading → strip before markdown.
3. **Token on static assets → `<script src="/app.js">` 401 → JS never executed** (page looked like dead HTML; diagnosed via identical content-extraction char counts across reloads). Fix: auth only `/api/` paths.
4. Several `str_replace` tool calls rejected when the `command` param was malformed — re-issue carefully.
